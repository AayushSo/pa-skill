# Reading list

**Scope:** articles and papers to read, and what came of reading them.

**Detailed docs:** `notes.md` (one short entry per finished item) · `items.json` (the list itself; the page and
`tools/readinglist.py` edit it).

## Key facts
- Items are triaged on the widget page (Quick links → Reading list): unread → reading → done / dropped.

## Standing decisions (do not re-litigate)
- Nothing goes on the list without a link.

## Definition of done
- An item is done when its takeaway is written in `notes.md`.
